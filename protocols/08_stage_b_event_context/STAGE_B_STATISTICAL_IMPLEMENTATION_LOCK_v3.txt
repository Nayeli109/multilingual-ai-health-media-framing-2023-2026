6. CLASS SPACE
============================================================

0, 1, ..., K-1.

{0, 1, ..., K-1}.

Macro-F1 is computed with:

    y_pred,
    labels=list(range(K)),
    average="macro",
    zero_division=0
)

The complete declared class space is therefore retained even if one
class receives no predictions.

============================================================
12. BOOTSTRAP
============================================================

Replicates:
10,000.

Bootstrap type:
paired stratified article-level bootstrap.

Stratification variable:
gold_id.

For each task:

1. Partition the 199 articles by gold_id.

2. Within each class stratum independently, sample article indices with
   replacement.

3. Draw exactly the original number of articles in that stratum.

4. Concatenate sampled strata in ascending gold_id order.

5. Apply the identical sampled article indices to both systems in the
   paired contrast.

6. Recompute both systems' Macro-F1 from their ensemble probabilities
   and sampled gold labels.

7. Record:

   Delta_boot =
   MacroF1(system_A_boot)
   -
   MacroF1(system_B_boot)

Confidence interval:

numpy.quantile(
    bootstrap_deltas,
    [0.025, 0.975]
)

No BCa correction.

No studentization.

No fold-level bootstrap.

No seed-level bootstrap.

The descriptive quantity:

mean(Delta_boot > 0)

is saved but must not be interpreted as a Bayesian posterior
probability.

============================================================
14. PAIRED PROBABILITY-VECTOR RANDOMIZATION
============================================================

Replicates:
10,000.

Randomization unit:
article.

For each article and replicate, independently draw one Bernoulli(0.5)
swap indicator.

If swap = 0:

system-A probability vector remains assigned to A;
system-B probability vector remains assigned to B.

If swap = 1:

the entire K-dimensional probability vector from A and B is exchanged
for that article.

All K class probabilities move together.

Class coordinates may never be independently permuted.

After swaps:

1. take argmax of randomized probability vectors;
2. compute Macro-F1 for randomized A;
3. compute Macro-F1 for randomized B;
4. compute:

   Delta_perm =
   MacroF1(A_perm)
   -
   MacroF1(B_perm)

The observed test statistic is:

Delta_observed =
MacroF1(A_observed)
-
MacroF1(B_observed)

Two-sided p-value:

p =
(
    1
    +
    sum(
        abs(Delta_perm)
        >=
        abs(Delta_observed)
    )
)
/
(10000 + 1)

The comparison uses >=, not >.

The +1 correction is mandatory.

16. BENJAMINI-HOCHBERG PROCEDURE
============================================================

BH is implemented separately for exactly two families.

FAMILY 1:

VERIFIED_CONTEXT
vs
STAGE_A_NO_EVENT

Three p-values:

primary_frame
stance
misinformation_relation


FAMILY 2:

VERIFIED_CONTEXT
vs
PERMUTED_CONTEXT

Three p-values:

primary_frame
stance
misinformation_relation


Implementation:

Given m = 3 p-values:

1. sort p-values ascending;

2. for sorted rank i in 1..m compute:

   raw_q_i =
   p_i * m / i

3. enforce monotonicity from largest rank to smallest:

   q_i =
   min(
       raw_q_i,
       q_{i+1}
   )

4. cap adjusted values at 1.0;

5. restore original task order.

No p-values are pooled across the two families.

No descriptive secondary metric enters BH correction.
