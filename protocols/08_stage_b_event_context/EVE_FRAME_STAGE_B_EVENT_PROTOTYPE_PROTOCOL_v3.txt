VERIFIED EVENT PROTOTYPE CONSTRUCTION PROTOCOL v3
==================================================

STATUS
Frozen before event-prototype construction and before any Stage-B
supervised training.

This stage performs deterministic aggregation only.

No supervised model is trained here.

==================================================
1. SCIENTIFIC PURPOSE
==================================================

For each LegacyAux target article with independently verified
same-event background neighbors, construct one frozen event-context
prototype.

The prototype represents the verified external event context and is
kept separate from the trainable Stage-B target-document encoder.

==================================================
5. PROTOTYPE DEFINITION
==================================================

For target article i, let R_i be the set of all background documents
accepted by the frozen event verifier.

For every context-available article:

e_i = (1 / |R_i|) * sum_{j in R_i} h_j

where:

h_j =
the frozen 768-dimensional XLM-R background representation.

Every verified neighbor receives exactly equal weight.

No verifier probability is used as a weight.

No cosine similarity is used as a weight.

No temporal-distance weighting is used.

No learned attention is used.

No top-k truncation is used.

All verified neighbors are retained.

==================================================
6. NUMERICAL AGGREGATION
==================================================

Input vectors are stored as float32.

For deterministic numerical aggregation:

1. load each selected background vector;
2. convert selected vectors to float64;
3. compute the arithmetic mean in float64;
4. verify all values are finite;
5. convert the final prototype to float32 for storage.

Stored prototype dtype:

float32.

Expected prototype dimension:

768.

==================================================

==================================================

Frozen Stage-B architecture protocol SHA256:

076ca9b3a99997b83d1ce43ca75fa59cc151f968d6c34c9fae92ef1ddf96c93f

The resulting event prototype e_i is the frozen input to the
predeclared Stage-B context projection:

c_i =
m_i * LayerNorm(W_c e_i + b_c)

g_i =
m_i * sigmoid(w_g^T [z_i ; c_i] + b_g)
