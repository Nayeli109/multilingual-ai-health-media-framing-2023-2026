==================================================
5. OVERLAP-AWARE DOCUMENT POOLING
==================================================

The implementation must reproduce the frozen Stage-A procedure.

For every retained chunk:

1. obtain last_hidden_state;
2. ignore special tokens;
3. ignore zero-length offset tokens;
4. define each token key as:

   (character_start, character_end, token_id)

5. if an overlapping token key appears in more than one chunk,
   average its hidden vectors across repeated appearances;
6. average all resulting unique-token vectors.

The resulting document representation is one 768-dimensional vector.

No CLS-only pooling is permitted.

No simple mean-of-chunks pooling is permitted.

No alternative attention pooling is permitted.
