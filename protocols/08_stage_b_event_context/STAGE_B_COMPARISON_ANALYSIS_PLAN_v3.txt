2. OOF ENSEMBLE CONSTRUCTION
==================================================

For each architecture arm and each target task:

1. Use only frozen OUTER_TEST predictions.

2. For each article, collect predictions from the five model seeds
   corresponding to that article's frozen outer fold.

3. Ensemble at probability level.

4. For each class k:

   p_bar_ik =
   (1 / 5) * sum_s p_isk

5. Final predicted class:

   argmax_k p_bar_ik

6. Argmax is applied only AFTER probability averaging.

7. Expected final OOF articles per task and arm:
   199.

8. Each LegacyAux article contributes exactly once to the final
   five-seed ensemble OOF prediction for a given task/arm.

Seeds are stochastic model fits and are NOT treated as independent
inferential observations.

Outer folds are partition machinery and are NOT treated as
independent inferential observations.

Inferential unit:
article.

==================================================
3. PRIMARY SCIENTIFIC FAMILY
==================================================

Comparison:

VERIFIED_CONTEXT
versus
frozen STAGE_A_NO_EVENT.

For each of the three tasks:

Delta_primary =
MacroF1(VERIFIED_CONTEXT)
-
MacroF1(STAGE_A_NO_EVENT)

Primary endpoint:
five-seed probability-ensemble OOF Macro-F1.

Direction of the observed delta is reported descriptively.

Primary hypothesis test:
two-sided paired article-level probability-vector randomization test.

Randomization replicates:
10,000.

Randomization unit:
article.

For each replicate, the paired probability vectors from the two
systems are exchangeable within article under the null.

The complete probability vector must move together when an article's
system assignment is swapped.

No class-wise independent swapping is permitted.

Test statistic:
difference in OOF Macro-F1.

Two-sided p-value:
computed from the absolute randomized delta relative to the absolute
observed delta, using a +1 finite-simulation correction:

p =
(1 + number of |Delta_perm| >= |Delta_observed|)
/
(1 + 10,000)

Multiplicity:
Benjamini-Hochberg FDR correction across EXACTLY the three task-level
p-values in this primary family.

Adjusted values are reported as q-values.

No pooling with the context-specificity family is permitted.

==================================================
4. PRIMARY UNCERTAINTY
==================================================

For each task-level primary contrast:

10,000 paired stratified bootstrap replicates.

Resampling unit:
article.

Stratification:
true target-task class label.

Within each true-label stratum, sample articles with replacement until
the original stratum size is recovered.

The same sampled article indices are applied to both compared systems.

For each bootstrap replicate:

Delta_boot =
MacroF1(VERIFIED_CONTEXT_boot)
-
MacroF1(STAGE_A_NO_EVENT_boot)

Report:
- observed Delta;
- 2.5th percentile of bootstrap deltas;
- 97.5th percentile of bootstrap deltas;
- descriptive bootstrap fraction Delta_boot > 0.

The bootstrap fraction is NOT a Bayesian posterior probability and is
NOT the primary hypothesis test.

==================================================
7. LABEL AND CLASS HANDLING
==================================================

Macro-F1 must use the full declared class set for the corresponding
task.

Classes absent from a particular prediction subset are not silently
removed from the declared task class space.

Final OOF metrics must be computed from article-level ensemble
predictions, not by averaging fold-level Macro-F1 values.

No seed-level Macro-F1 averaging is used as the primary endpoint.

==================================================
8. COMPARABILITY REQUIREMENTS
==================================================

Before inference, every paired task-level comparison must verify:

- identical article IDs;
- identical article count;
- identical true labels;
- one OOF article prediction per system;
- no duplicated article IDs;
- no missing probability vectors;
- finite probabilities;
- probability rows numerically sum to approximately 1;
- identical declared class ordering after explicit alignment.

If any of these fail, inference must stop.

==================================================
9. RANDOMNESS
==================================================

All bootstrap and randomization procedures must use fixed,
predeclared pseudorandom seeds in the statistical implementation lock.

The implementation lock must be frozen and hashed BEFORE the analysis
script is executed.

No seed may be chosen or changed after inspecting inferential results.

==================================================
10. INTERPRETATION RULES
==================================================

A numerical improvement alone is not called statistically supported.

For task-level confirmatory interpretation, the paired randomization
p-value and its within-family BH-adjusted q-value govern inferential
support.

Bootstrap confidence intervals quantify uncertainty but do not replace
the predeclared randomization/FDR decision rule.

A non-significant result is NOT evidence of equivalence.

No equivalence or non-inferiority claim is permitted because no
equivalence/non-inferiority margin or test is predeclared.

No claim of independent external validation is permitted from
LegacyAux-199.

LegacyAux results remain developmental evidence.
