EVE-FRAME STAGE A vs FROZEN BASE — ANALYSIS PLAN v3
====================================================

STATUS
Frozen after completion and audit of all 60 Stage-A runs, but before
inspection or computation of aggregate Stage-A OOF performance.

DEVELOPMENT DATA
LegacyAux-199.

IMPORTANT SCOPE
This is a development-set architectural comparison.

The Stage-A architecture was designed after inspection of the earlier
LegacyAux BASE-vs-DAPT error structure. Therefore, LegacyAux Stage-A
results are not treated as independent external validation.

Independent external evaluation remains reserved for EventGold-35,
which remains sealed.

SYSTEMS
Comparator:
XLMR_BASE independent single-task supervised fine-tuning from the
previous frozen experiment.

Candidate:
EVE_FRAME_STAGE_A_NO_EVENT.

STAGE-A ARCHITECTURE
Shared XLM-R encoder with three jointly optimized task-specific heads:
- primary_frame
- stance
- misinformation_relation

No event, language, region, source-domain, outlet, or topic features.

TASKS
1. primary_frame
2. stance
3. misinformation_relation

INFERENTIAL UNIT
Article.

Seeds are repeated stochastic fits and are NOT independent
observations.

OOF ENSEMBLING
For each target task, outer fold, and held-out article:

1. collect the five Stage-A probability vectors from seeds
   11, 29, 47, 83, and 131;
2. compute their elementwise arithmetic mean;
3. predict with argmax of the mean probability vector;
4. concatenate the four held-out folds.

This yields exactly one Stage-A OOF prediction per article per task.

The frozen BASE comparator uses the already frozen five-seed OOF
probability ensemble from the completed supervised experiment.

PRIMARY ENDPOINT
Macro-F1 over all 199 OOF articles.

PRIMARY CONTRAST
Delta = MacroF1(StageA) - MacroF1(BASE)

Positive Delta:
Stage A numerically higher.

Negative Delta:
BASE numerically higher.

No conclusion will be based on individual fold or seed performance.

PRIMARY PAIRED UNCERTAINTY
Paired class-stratified bootstrap at article level.

Replicates:
10,000.

Within each true-label stratum, articles are sampled with replacement
using the original stratum sample size.

The same sampled article indices are used for Stage A and BASE.

Report:
- observed Delta
- bootstrap mean Delta
- percentile 95% CI
- bootstrap P(Delta > 0)

PAIRED RANDOMIZATION TEST
10,000 article-level paired randomization replicates.

For each article independently with probability 0.5, swap the complete
Stage-A and BASE probability vectors.

Recompute predictions, Macro-F1, and Delta after each swap.

Two-sided plus-one p-value:

p = (1 + count(|Delta_null| >= |Delta_observed|)) / (10000 + 1)

MULTIPLE TESTING
Benjamini-Hochberg FDR correction across exactly the three
predeclared task-level Macro-F1 randomization p-values.

SECONDARY METRICS
Descriptive:
- balanced accuracy
- accuracy
- weighted F1
- per-class precision
- per-class recall
- per-class F1
- confusion matrices

MINORITY-CLASS DIAGNOSTIC
Because the frozen BASE benchmark showed multiple classes with zero
F1/recall, report descriptively:

- classes with BASE recall = 0
- corresponding Stage-A recall
- absolute recall change
- corresponding Stage-A F1
- number of previously unrecovered classes obtaining non-zero recall

This is a predeclared diagnostic, not a separate confirmatory family.

SEED STABILITY
For each task and architecture, combine the four held-out folds within
each model seed and calculate descriptive seed-specific OOF metrics.

Seeds are NOT used as independent observations for hypothesis testing.

FOLDS
Outer folds are NOT treated as n=4 independent observations.

CLASS HANDLING
All declared task classes are always included in Macro-F1 and
per-class calculations.

zero_division = 0.

No class is dropped because it was never predicted.

EVENTGOLD
EventGold-35 remains SEALED and must not be accessed by this analysis.

DECISION RULE
Interpretation will jointly consider:
- observed effect magnitude
- paired bootstrap 95% CI
- paired randomization p-value
- BH-adjusted q-value
- per-class error structure
- seed-level descriptive stability

A numerical sign alone is not evidence.

No Stage-A result may be used to alter the already completed Stage-A
training experiment.
