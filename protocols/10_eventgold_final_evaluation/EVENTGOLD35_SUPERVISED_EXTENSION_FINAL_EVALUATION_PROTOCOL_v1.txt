PURPOSE
-------
Perform the single final held-out supervised evaluation of the already
frozen STAGE_A_NO_EVENT model package on the prospectively human-annotated
supervised extension of the previously held-out EventGold35 document set.

This protocol does not reopen model development, architecture selection,
human annotation, adjudication, taxonomy definition, epoch selection,
checkpoint selection, or preprocessing design.

HISTORICAL PROTOCOL DEVIATION
-----------------------------
The original EventGold35 one-shot supervised evaluation was closed
without predictions or performance because the original EventGold35
annotation schema did not contain the three Stage-A supervised targets.

That failed schema-incompatible attempt remains permanently documented.

The present evaluation is a separately versioned prospective supervised
extension. It must not be described as though the Stage-A target labels
were part of the original EventGold35 annotation schema.

ADDITIONAL DESCRIPTIVE CLASS-LEVEL OUTPUTS
------------------------------------------
To support transparent interpretation of the small and imbalanced final
benchmark, the final evaluator will additionally report, separately for

- support;
- precision;
- recall;
- F1.

These class-level statistics are DESCRIPTIVE ONLY.

They do not replace, modify, select, tune, or redefine the primary or
secondary frozen metrics.

They must use the complete frozen class list and zero_division=0.

CONFUSION MATRICES
------------------
A confusion matrix will be reported separately for each task using the
complete frozen label universe for both true and predicted axes.

Confusion matrices are descriptive only.

No class merging or post-hoc category collapsing is permitted.

BOOTSTRAP UNCERTAINTY
---------------------
Primary uncertainty analysis:

10,000 bootstrap replicates per task.

Resampling unit:
ARTICLE.

Stratification:
observed final-gold true label within task.

For every observed gold class, sample with replacement the same number
of article indices originally belonging to that class.

For each replicate, Macro-F1 is computed using the COMPLETE frozen task
label universe.

95% interval:

NumPy quantile at 0.025 and 0.975
with method="linear".

The bootstrap interval is descriptive.

No bootstrap-based model selection is permitted.

INTERPRETATION CONSTRAINTS
--------------------------
The final benchmark contains only 35 articles.

Results support a carefully framed held-out benchmark assessment and
must not be represented as population-representative performance.

Seeds are stochastic fits and are not independent inferential units.

The EventGold supervised extension must be described as:

"a prospectively human-annotated supervised extension of the previously
held-out EventGold35 document set."
