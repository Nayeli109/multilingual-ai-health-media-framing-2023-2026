BOOTSTRAP
---------
Replicates:
10000

Scheme:
Paired article-level stratified resampling within true-label strata.

Statistic:
Macro-F1(A) minus Macro-F1(B).

Confidence interval:
Empirical percentile 2.5% and 97.5%.

The bootstrap interval and fraction delta > 0 are supportive
uncertainty summaries.

They do not replace the frozen randomization-test + BH decision rule.

RANDOMIZATION
-------------
Replicates:
10000

Unit:
Article.

Operation:
For each randomization replicate, swap the complete probability
vector between systems A and B independently at article level.

Statistic:
Macro-F1(A) minus Macro-F1(B).

P-value:
Two-sided, using the same finite-sample randomization implementation
as the frozen Stage-B analysis.

ARCHITECTURE ELIGIBILITY
------------------------
An architecture is eligible only if, for at least one SAME task,
both of the following hold:

A. INCREMENTAL:
   VERIFIED_CONTEXT vs STAGE_A_NO_EVENT
   delta Macro-F1 > 0
   AND BH q < 0.05.

B. CONTEXT_SPECIFICITY:
   VERIFIED_CONTEXT vs the same architecture's PERMUTED_CONTEXT
   delta Macro-F1 > 0
   AND BH q < 0.05.

The condition must occur on the same task.

FINAL ARCHITECTURE RULE
-----------------------
Default:
STAGE_A_NO_EVENT.

If neither V4 architecture is eligible:
select STAGE_A_NO_EVENT.

If exactly one V4 architecture is eligible:
select that architecture.

If both V4 architectures are eligible:
compute the equal-weight arithmetic mean of VERIFIED_CONTEXT
Macro-F1 across the three tasks for each eligible architecture.

Select the larger mean.

Exact numerical tie:
compare to 12 decimal places.

If still tied:

No other tie-breaker is permitted.
